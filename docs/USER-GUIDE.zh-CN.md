# ChatGPT / Codex 额度状态栏

## 用户操作手册

> 给第一次使用 Windows 状态栏的用户：从下载到看到实时额度通常只需要几分钟。

![PLUS 套餐迷你状态栏界面示意](assets/preview/statusbar-plus.png)

![Usage Hub 大屏界面示意](assets/preview/usage-hub-plus.png)

图片使用脱敏演示数据，只用于说明布局和功能；百分比、套餐和时间会以你的账户实际返回为准。

## 先了解三件事

1. 这是一个便携式 Windows 小工具，不安装后台服务，也不要求管理员权限。
2. 它不负责登录，只读取本机 Codex CLI 已完成的 ChatGPT OAuth 登录状态。
3. 它不只支持 Plus。只要官方接口为当前账户返回额度窗口，Free、Go、Plus、Pro、Team、Business、Enterprise、Edu 等计划都按实际结果展示。

## 三分钟开始使用

### 第一步：完成 Codex 登录

打开 PowerShell 或 Windows Terminal，运行：

```powershell
codex login
```

登录完成后关闭终端即可。状态栏会读取 Codex 默认目录中的登录文件：

```text
%USERPROFILE%\.codex\auth.json
```

如果你使用了 `CODEX_HOME`，程序会优先读取该目录下的 `auth.json`。

不要打开、复制或分享这个文件。它包含 OAuth 凭据，不能上传到 Issue、聊天或 GitHub。

### 第二步：下载程序

从 [GitHub Releases](https://github.com/chengaliang/chatgpt-codex-usage-statusbar-windows/releases/latest) 下载 `SubscriptionStatus.exe`。

程序是便携版：建议单独建立一个文件夹保存它，例如：

```text
C:\Tools\ChatGPTCodexStatusBar\SubscriptionStatus.exe
```

首次使用可以先验证文件完整性。Release 页面同时提供 `SHA256SUMS.txt`，在 PowerShell 中运行：

```powershell
Get-FileHash .\SubscriptionStatus.exe -Algorithm SHA256
```

将输出的 SHA-256 与清单中的值比较。只从项目 Release 页面下载，不要为了运行未知文件而关闭 Windows 安全防护。

### 第三步：启动

双击 `SubscriptionStatus.exe`。如果你是从源码仓库运行，请保留完整目录结构并双击根目录的 `start-statusbar.cmd`。

启动后，状态栏会出现在启动时所在显示器的右下角、任务栏上方。它不会出现在任务栏按钮或 `Alt+Tab` 列表中，程序图标会在 Windows 通知区域显示。

第一次启动默认开启当前 Windows 用户的开机自启。这个设置不需要管理员权限，之后可以随时关闭。

## 如何阅读状态栏

状态栏优先显示官方返回的两个常见额度窗口：

| 标记 | 含义 |
| --- | --- |
| 左侧套餐标签 | `PLUS`、`PRO`、`TEAM` 等短标签，来自 OAuth 套餐声明；无法识别时显示 `GPT` |
| `5h` | 约 5 小时额度窗口 |
| `7d` | 约 7 天额度窗口 |
| 百分比 | 已使用比例，不是剩余比例 |
| 日期时间 | 下一次重置时间，使用本机时区 |
| `实时` | 最近一次在线查询成功 |
| `缓存` | 网络或 OAuth 暂时不可用，显示最近一次成功数据 |

百分比颜色用于快速提醒：接近 80% 会进入注意色，达到 95% 会进入高风险色。数字仍然是官方返回的实际值，动画不会改变额度判断。

如果 OAuth 凭据提供了官方套餐声明，左侧会显示对应的短标签，例如 `PLUS`；展开 Usage Hub 后，标题会显示完整名称，例如 `GPT Plus`。套餐只用于识别和展示，不会限制额度查询功能，也不会把未知远端文本直接写入界面。若凭据没有套餐声明，程序会保留通用的 `GPT` 标签。

如果官方返回了其他窗口，迷你栏会选取前两个最有代表性的窗口；Usage Hub 会列出全部窗口。没有重置时间时显示 `--`，表示官方没有提供可用时间。

刷新成功后，状态栏会播放一次短促的同步脉冲：能量线、星芒和高光会快速扫过，然后自动恢复安静状态。缓存、失败、隐藏窗口或关闭动效时不会播放过期庆典。

## 日常操作

| 想做什么 | 怎么做 |
| --- | --- |
| 手动刷新 | 点击圆形箭头，或右键选择“立即刷新” |
| 移动位置 | 拖动状态栏的空白区域 |
| 打开大屏 | 点击空白区域、展开按钮，或右键选择“打开 Usage Hub” |
| 唤起大屏 | 按 `Ctrl+Alt+U` |
| 隐藏状态栏 | 点击 `×`，程序会留在通知区域 |
| 恢复状态栏 | 双击通知区域中的项目图标 |
| 彻底退出 | 右键选择“退出”，或在 Usage Hub 点击“退出程序” |
| 防止重复窗口 | 再次启动即可，程序会聚焦已有实例 |

关闭 `×` 只是隐藏，不是退出。只有“退出”才会结束进程；这是为了让开机自启和定时刷新保持稳定。

## Usage Hub 大屏

Usage Hub 适合查看完整额度和趋势：

- 每个官方额度窗口都有独立的环形进度、已使用比例、剩余比例和下一次重置时间。
- 底部趋势图只使用本地百分比和时间，不上传历史数据。
- 至少成功刷新两次后，趋势图才有足够数据绘制曲线。
- 大屏会显示当前周期的消耗速度、趋势方向和预计耗尽时间；预计时间是本地估算，不是官方承诺。
- 定时刷新或托盘刷新时，如果 Hub 正在打开，它会同步最新数据和一次同步脉冲。

大屏底部常用入口：

| 按钮 | 用途 |
| --- | --- |
| 刷新数据 | 立即重新查询官方额度 |
| 设置 | 修改外观、刷新和通知偏好 |
| 诊断中心 | 检查 OAuth、网络、缓存和启动项 |
| 复制摘要 | 复制不含凭据的安全摘要 |
| 导出趋势 | 导出本地 CSV 趋势 |
| 项目主页 | 打开 GitHub 项目 |
| 回到状态栏 | 关闭大屏并回到迷你栏 |
| 退出程序 | 结束整个程序 |

快捷键：在 Usage Hub 中按 `Ctrl+C` 复制安全摘要，按 `Ctrl+E` 导出趋势，按 `Esc` 关闭大屏。

在 Usage Hub 中按 `F5` 也可以刷新数据。

## 设置建议

右键状态栏或托盘图标，选择“设置”。保存后设置会立即生效。

| 设置 | 推荐值 | 说明 |
| --- | --- | --- |
| 自动刷新 | 5 分钟 | 日常使用的平衡值，可选 1/5/10/15/30/60 分钟 |
| 历史保留 | 30 天 | 仅保存本地趋势，长期观察可选 90 天 |
| 主题 | 跟随系统 | 也可选择深色、浅色或石墨 |
| 背景样式 | 实色 | 半透明 85% 和高透明 65% 更适合叠加在桌面上 |
| 随 Windows 启动 | 开启 | 开机后自动回到状态栏 |
| 启动延迟 | 立即查询 | 如果代理或网络启动较慢，可改为 5/15/30 秒 |
| 启动时检查更新 | 关闭 | 开启后只提示公开 Release，不会自动安装 |
| 记住上次位置 | 开启 | 适合多显示器或固定工作区 |
| 平滑动效与状态反馈 | 开启 | 控制进度过渡和刷新同步脉冲 |
| 全局快捷键 | `Ctrl+Alt+U` | 与其他软件冲突时可以关闭 |

通知默认关闭。需要提醒时，可以开启“额度接近阈值时通知”，再设置 50% 到 100% 的阈值。周期重置提醒和“预测 2 小时内耗尽”提醒可以单独开启，程序会按每个额度周期去重，避免重复弹窗。

### 本地数据与清理

程序的设置、最近成功缓存和趋势历史保存在：

```text
%LOCALAPPDATA%\ChatGPTCodexUsageStatusBar
```

右键菜单的“打开数据目录”可以直接打开这个位置。里面不保存 OAuth Token；“清除趋势历史与导出”和“清除最近成功缓存”是两个独立操作，按需选择即可。

## 网络与代理

程序默认使用 Windows 系统代理；如果系统没有配置代理，就尝试直接连接。Clash Verge 不是必需品。

只有在你的网络确实需要本地代理时，才在启动前设置 `CLASH_MIXED_PROXY`。示例端口仅供参考，请以 Clash Verge 当前的 HTTP 或混合端口为准：

```powershell
$env:CLASH_MIXED_PROXY = "http://127.0.0.1:7890"
Start-Process -FilePath .\SubscriptionStatus.exe -WorkingDirectory (Resolve-Path .)
```

这个变量只影响当前 PowerShell 窗口。想长期使用时，可以在“系统属性 → 高级 → 环境变量”的当前用户变量中设置；不需要时删除该变量即可。只填写完整的 `http://` 或 `https://` 地址，不要填写订阅链接、账号或密码。

## 安全更新

右键选择“检查更新”后，程序只读取公开 GitHub Release 信息。确认更新后会打开 Release 页面，不会在后台覆盖正在运行的程序。

下载新版本后，先退出当前程序，再用 `Get-FileHash` 对照 Release 提供的 `SHA256SUMS.txt`，确认一致后替换旧文件。开启“启动时检查更新（仅提示）”后，程序只在首次查询完成后提醒一次，不会自动下载或安装。

## 诊断与反馈

遇到问题时，优先按以下顺序处理：

1. 右键状态栏，选择“诊断中心”。
2. 点击“重新检查”，等待检查完成。
3. 阅读每一项的状态和“下一步”。
4. 需要提交 Issue 时，点击“复制安全摘要”。

诊断中心只展示固定检查结果，例如 OAuth 是否可读、网络协议、额度查询状态、缓存/历史是否存在、快捷键冲突和开机启动项。它不会展示 Token、账户 ID、代理地址、完整接口响应或本机文件路径。

提交 Issue 时请附上：

- Windows 版本和程序版本。
- 复现步骤、预期结果和实际结果。
- 状态栏显示的是实时、缓存还是错误状态。
- 脱敏后的诊断摘要。

绝不要附上 `auth.json`、OAuth Token、账户 ID、代理订阅地址、完整响应、日志或包含个人信息的截图。

## 常见问题

### 只支持 ChatGPT Plus 吗？

不是。程序不根据计划名称限制功能，只展示官方接口为当前账户返回的额度窗口。计划名称未知时会安全地显示通用的 ChatGPT 标签。

### 需要 OpenAI API Key 吗？

不需要。程序使用 Codex CLI 的 ChatGPT OAuth 会话，不读取 API Key 账单额度。

### 状态栏显示“缓存”是不是额度丢了？

不是。它表示最近一次成功数据仍然保留，但本次网络或 OAuth 查询没有成功。先重新登录或检查网络，再点击刷新；工具提示会显示缓存时间和安全错误提示。

### 看不到窗口怎么办？

先查看 Windows 通知区域并双击项目图标，再重新运行程序。重复启动不会创建第二个窗口，而是尝试恢复并聚焦已有状态栏。仍然没有反应时，确认 Release 下载完整，或在源码目录通过 `start-statusbar.cmd` 启动；最后才考虑在任务管理器结束 `SubscriptionStatus.exe` 后重新启动。

### 双击提示被 Windows 拦截怎么办？

先确认文件来自项目 Release，并完成 SHA-256 比对。只有在来源和校验都确认后，才按 Windows 提示继续运行；不要关闭系统安全防护来绕过未知文件警告。

### 为什么趋势图还是空的？

趋势需要至少两次成功在线刷新。网络失败或只读取缓存时，不会伪造新的趋势点。

### 如何卸载？

先右键关闭“开机自启”，再选择“退出”，最后删除你保存的程序文件夹即可。程序不会删除 Codex CLI 的登录状态；如果还要清理本地数据，可在右键菜单分别选择“清除趋势历史与导出”和“清除最近成功缓存”。

## 隐私边界

- OAuth 凭据只在内存中用于固定 HTTPS 额度请求，不写回 `auth.json`。
- 程序不上传 Token、账户 ID、完整响应、趋势或桌面截图。
- 本地缓存和历史只保留 Provider、窗口秒数、百分比和时间。
- 导出的 CSV 不包含 Provider、账户 ID 或凭据。
- 更新检查只读取公开 GitHub Release 元数据，确认后打开页面，不会替换正在运行的 EXE。
