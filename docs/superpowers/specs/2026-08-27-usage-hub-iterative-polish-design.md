# Usage Hub 连续迭代设计

**日期：** 2026-08-27
**状态：** 用户已授权自主连续开发
**范围：** 在 v0.8.0 的状态栏、Usage Hub、托盘、设置和诊断基础上完成至少三轮增强

## 目标

- 让用户不打开大屏也能快速判断额度健康度、数据新鲜度和是否需要操作。
- 让 Usage Hub 从“查看面板”变成“查看、预测、复制、维护”的本地工作区。
- 所有洞察只使用已经落盘的脱敏历史；不读取新凭据、不上传历史、不引入遥测。
- 保持单 EXE、Windows 自带 .NET Framework 编译、`Alt+Tab` 隐藏、主题一致和低资源占用。

## 三轮路线

### 第一轮：洞察与预测

新增纯逻辑 `UsageInsights`，从 `UsageSnapshot` 和 `HistoryPoint` 计算：

- 当前窗口的最近消耗速度（百分点/小时）；
- 按最近有效斜率推算的“预计耗尽”时间，没有足够数据时返回空值；
- 最近成功时间、缓存年龄和趋势方向（上升、稳定、下降）；
- 受控的健康标签：正常、接近阈值、数据过期、等待历史。

Usage Hub 的窗口卡显示速度和预测，页首状态带显示健康标签。预测只是一种本地估算，文案明确“按最近历史”，不伪装成官方限制。

### 第二轮：快捷操作与通知

- 注册可配置的本地全局快捷键 `Ctrl+Alt+U` 打开/聚焦 Usage Hub；注册失败只进入诊断，不阻塞主程序。
- Hub 增加“复制安全摘要”操作，复用现有脱敏诊断报告；增加 `Ctrl+C` 快捷键。
- `NotificationEvaluator` 新增重置周期通知和可选“预测即将耗尽”提醒，沿用窗口秒数与有效 `reset_at` 去重。
- 所有按钮、关闭、刷新、最大化和复制操作可通过 Tab/Enter/Space 到达；Esc 只关闭当前工作区。
- 设置页增加快捷键和通知开关，默认保持克制，不改变现有用户偏好。

### 第三轮：维护工具与视觉细节

- `HistoryStore` 提供脱敏 CSV 导出，文件只包含窗口、百分比、观测时间和重置时间；Hub 和诊断中心提供导出/打开所在目录入口。
- 增加“清理历史”确认流程，只删除应用自己的历史文件，不触碰缓存和 Codex 凭据。
- 诊断摘要增加历史点数量、最近成功年龄和预测可用性，继续使用固定白名单。
- Hub 增加轻量粒子/辉光层、状态变化过渡和 reduced-motion 路径；动画仍由一个 Timer 驱动，隐藏窗口时停止。
- 补齐 AccessibleName、键盘焦点顺序、颜色之外的状态文本和高 DPI 最小尺寸断言。

## 边界与错误恢复

- 无历史、历史损坏、负斜率、非有限百分比和缺少 `reset_at` 时不显示预测数字，改用明确的“数据不足/等待下一次成功刷新”。
- 全局快捷键冲突、CSV 写入失败、剪贴板不可用和通知失败均只显示短提示并保持状态栏可用。
- 导出文件写入 `%LOCALAPPDATA%\\ChatGPTCodexUsageStatusBar\\exports`，失败时不回退到桌面或任意路径。
- 动效关闭时仍以低频重绘倒计时和状态文本；动画开启时不阻塞查询线程。

## 验收与门禁

- 每轮先增加纯逻辑或反射 smoke，再实现；每轮通过 `csc /warnaserror`、P0/P1 smoke、敏感信息扫描和进程响应检查。
- 预测测试覆盖两点、单点、零时间差、下降趋势、非有限值和超过 100% 边界。
- 快捷键测试覆盖注册成功、冲突失败、重复注册和窗口聚焦；通知测试覆盖重置、阈值和重复刷新去重。
- 导出测试确认 CSV 不含 Token、账户 ID、代理 URI、完整响应或本地凭据路径。
- 最终发布只包含 `SubscriptionStatus.exe`、`SHA256SUMS.txt` 和中文/英文变更说明，Release 元数据保持 UTF-8，无问号乱码。
